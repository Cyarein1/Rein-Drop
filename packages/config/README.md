# @rein-drop/config

Shared configuration for workspaces.

- `tsconfig/library.json` - base for `packages/*` libraries (ESM, strict, emits `dist/`).

Usage in a package `tsconfig.json`:

```json
{
  "extends": "@rein-drop/config/tsconfig/library.json",
  "compilerOptions": { "outDir": "dist", "rootDir": "src" },
  "include": ["src"]
}
```

Apps (`web`, `mobile`, `api`, `worker`) keep the tsconfig generated by their framework
tooling, because Next.js, Expo and Nest each require framework-specific settings.
