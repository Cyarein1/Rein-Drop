# German glossary and tone (draft - for the native reviewer)

The decisions the draft follows. The reviewer may change any of them; then update the catalogs
consistently.

## Tone
- **„du“, informal**, friendly and direct, like modern German consumer apps and reseller communities.
  *Reviewer: confirm „du“ vs „Sie“* (eBay.de mostly uses „Sie“; Kleinanzeigen uses „du“).
- **Short, plain sentences.** No anglicisms where a common German word exists, except established
  reseller terms.
- **German quotation marks** „…“; numbers / money / dates via the locale (`1.234,50 €`, `15.10.2026`).
